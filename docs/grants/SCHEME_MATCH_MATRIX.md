## Immediate application sequence

1. Verify company incorporation, shareholding, PAN, registered address and authorized signatory.
2. Prepare and submit DPIIT recognition only with truthful innovation and stage evidence.
3. Recheck MP Startup Portal during the published quarterly call window and confirm an empanelled incubator.
4. Do not submit a grant application using synthetic metrics as market validation.
5. Build signed pilot evidence while monitoring official MeitY/MSME/incubator calls.
