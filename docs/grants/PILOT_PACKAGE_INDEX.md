# XeroWA AI 30–60 day pilot package

Status: ready-to-use blank package for a controlled first cohort of three businesses. No business has been recruited, contacted, signed or measured by creating these files.

## Intended cohort

The first cohort is fixed to one business from each of these verticals:

1. Coaching institute
2. Salon
3. Gym

Dental is deferred to a second cohort because medical-data and clinical-claim risks require a separate legal/security gate. Real estate is also deferred to a second cohort because the generic XeroWA tenant workflow must remain clearly separated from the standalone X7 RealEstate product boundary. The standalone X7 RealEstate repository, database, branding and customer data remain outside this package.

## Use order

| Gate | File | Completion evidence |
|---|---|---|
| Method | `PILOT_PROTOCOL.md` | Scope, 30–60 day window, stop conditions and measurement method approved |
| Intent | `PILOT_LOI_TEMPLATE.md` | Completed/signed private LOI or pilot order |
| Data terms | `PILOT_CONSENT_TEMPLATE.md` | Counsel-reviewed executed agreement |
| Retention | `PILOT_DATA_RETENTION_SCHEDULE.md` | Approved periods, subprocessors, close-out and deletion SLA |
| Onboarding | `PILOT_ONBOARDING_CHECKLIST.md` | Dated go/no-go record with named owners |
| Baseline | `PILOT_BASELINE_MEASUREMENT_SHEET.md` | Frozen definitions, baseline and targets labeled as targets |
| Security | `PILOT_SECURITY_REVIEW_CHECKLIST.md` | Independent runtime results and resolved/owned findings |
| Weekly operations | `PILOT_WEEKLY_EVIDENCE_REVIEW.md` | Dated weekly KPI/safety/change reviews |
| Final results | `PILOT_RESULTS_TEMPLATE.md` | Frozen aggregate results, limitations and dual sign-off |
| Evidence storage | `pilot-evidence/README.md` | Private pseudonymous folder and manifest; no raw PII in Git |

## Minimum launch gate

A business does not enter the real-pilot measurement window until agreements, retention, baseline, approved replies, operator training, tenant routing, stop controls and required security checks are complete. Any target remains a target until the result template contains a sourced, dated, signed measurement.

## External-action boundary

This package does not authorize customer contact, document execution, DPIIT/grant submission, public customer naming, result publication or approval claims. Each requires explicit owner authorization and the stated evidence gate.
