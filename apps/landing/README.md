# XeroWA AI - Landing / Offer Pages

This app is the vertical offer-page generator for XeroWA AI packs. The first pack is SiteVisit AI, and the same shell should support clinics, coaching, gyms, and local services.

First pages to support:

- XeroWA SiteVisit for real-estate builders and brokers
- XeroWA Appointment for clinics
- XeroWA Admission for coaching institutes
- XeroWA Fitness Intake for gyms and dietitians
- XeroWA Callback for local services

```bash
cp .env.local.example .env.local
npm install
npm run dev   # http://localhost:3001
```

The first pivot landing page should sell the 7-day WhatsApp AI receptionist trial, not the full internal agent architecture.
